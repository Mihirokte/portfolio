# prep — study & practice portal

A self-contained study/practice app that lives inside the portfolio, served at
`/prep/` (and standalone at prep.mihirokte.info). Everything runs client-side;
all progress is saved in the browser.

## How it's organised

```
prep/
├── main.tsx            entry: Redux Provider + PersistGate → App
├── App.tsx             router: a declarative route table (hash-based)
├── useHashRoute.ts     tiny hook: current #hash, re-renders on change
├── areas.ts            the home grid: DSA (problems) + study courses
├── selectors.ts        pure data joins (chapter ↔ its problems, leftovers)
├── judge.ts            Pyodide-backed Python syntax validator (web worker)
├── storage.ts          progress export / import (JSON file)
│
├── routes/             one file per page — all presentational
│   ├── Home.tsx          the 5-area grid
│   ├── Study.tsx         CoursePage: lessons → practice → more problems → refs
│   ├── Lesson.tsx        a single lesson + mark-as-read + prev/next
│   ├── Dsa.tsx           the DSA problem list (drill-only area)
│   └── Drill.tsx         a single problem: editor + validator, or discussion drill
│
├── components/         reusable UI, no page logic
│   ├── ui.tsx            Bar, ProblemRow, LessonRow, status chips, notes
│   ├── nav.tsx           TopBar, NotFound
│   ├── Markdown.tsx      renders lesson markdown; ```mermaid → SequenceDiagram
│   ├── SequenceDiagram.tsx  tiny SVG renderer for sequence diagrams
│   └── Editor.tsx        CodeMirror 6 Python editor
│
├── store/              Redux Toolkit + redux-persist
│   ├── progressSlice.ts  lessons {read} + problems {status, code, notes}
│   └── index.ts          store, persistor, legacy-localStorage migration
│
├── content/            THE DATA — study courses, hand-authored
│   ├── types.ts          Course → Chapter → Lesson, + Reference

│

```

## The two content models

- **Study** (`content/`): a `Course` has `Chapter`s, each with `Lesson`s (markdown).
  A chapter MAY claim practice problems by id (`problemIds`) so the course page
  shows, in textbook order: lessons → that chapter's problems → leftover problems
  → references. Study-only courses (Production & Ops, Security) simply omit
  `problemAreaKey` and carry no problems.
- **Practice** (`data/`): problems live in `drills.ts`; the runnable DSA subset
  adds starter code + a function signature in `packs.ts`. DSA is drill-only.

## Adding content

- New study area → write `content/<area>.ts`, add it to `COURSES` in `content/index.ts`.
  It appears on the home grid automatically.
- New route → add one line to the `ROUTES` table in `App.tsx` + a component in `routes/`.

## Progress & persistence

All progress is a single Redux slice, persisted to localStorage via redux-persist
(key `prep-v2`). Nothing is sent anywhere. Export/import is a plain JSON file.
